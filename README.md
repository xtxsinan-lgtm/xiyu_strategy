# 湘南行军 · Godot 学习版

基于本机《Rise of the White Sun / 白日升》教程实玩观察制作的独立策略游戏原型。Godot 4.6.2 已运行验证。地图、城门、山脉、纸纹全部由程序绘制，没有导入原游戏素材。

## 打开与运行

在 Godot 项目管理器中选择「导入」，打开本目录的 `project.godot`，进入编辑器后按 **F5**。macOS 也可以双击「启动学习版.command」，使用 `/Applications/Godot.app` 启动。

设计分辨率 1440 × 900，窗口会等比缩放。字体优先使用系统中文字体；其他系统建议安装 Noto Sans CJK SC。无需插件和外部素材。

## 游戏操作

目标：十二周内占领长沙，再守住两周。

- 底部选择人物。两个人的气力、资金、支持者、人脉独立。
- 点击地图上的圆形部队标记；侧栏显示指挥官、士兵、劳工、训练与士气。
- 先选指挥官并发军饷。招募劳工改善补给；操练提高战力。
- 点击相邻城市，在「地区」页行军或进攻。每支部队每周移动一次。
- 消灭守军后，到「部队」页执行接管地区，才能取得税收和控制权。
- 唐生智可兴办实业、赈济安民。税收在周结算时进入唐的账户。
- 「下一周」恢复气力、收税、强化敌方守军。欠饷造成逃兵和士气下降。
- 控制长沙后，驻军战力至少 9,000 才能抵御反攻。连续守住两周即胜利。
- 顶部保存、读取使用 Godot 的 `user://campaign.json`，不会修改原游戏存档。

一条可验证的通关路线：

1. 第一周：选白崇禧和第七军，发饷，招募一次劳工，进攻株洲，接管株洲。
2. 下一周：唐向白转交 50 资金；白发饷、再招一次劳工，进攻长沙，接管长沙。
3. 下一周：唐再次转交资金，白发饷并驻守；再推进一周，完成胜利条件。

第七军初始劳工少于士兵的两倍，因此第一次行军仍会有后勤损耗。这是有意保留的资源取舍。

## 从哪里读代码

- `scripts/campaign.gd`：纯规则层。人物、城市、军队用字典存储；执行行动前检查权限与成本，执行后发送 `changed` 信号。
- `scripts/strategic_map.gd`：地图显示。`_draw()` 画地形、铁路和标记；`_gui_input()` 将点击转换成城市或部队选择。
- `scripts/main.gd`：界面层。创建 Control 节点、连接按钮与规则方法，收到信号时刷新面板。
- `main.tscn`：入口场景。界面节点在运行时创建，所以编辑器里主要显示入口节点。
- `tests/test_campaign.gd`：规则检查，覆盖不能越权、失败不扣资源、欠饷、行军、接管、税收、通关及存档恢复。

建议学习顺序：先看 `spend()` → `pay()` → `march()` → `next_week()`，再看 `changed.connect(refresh)`，最后看地图的绘制与点击。修改规则后无需改地图按钮。

可练习的修改：修改一座城市的税收；把操练收益从 12 调成 8；增加外交行动；将字典换成自定义 Resource；将代码生成的 UI 拆成独立 `.tscn` 场景。

## 原作观察与本版简化

实际打开并体验了原作中文教程，查看人物角色、独立资源、资源转交、招募说明、军队管理与行军规则，尝试错误指挥官的行军命令，再使用白崇禧将第七军从衡阳运往郴州，查看运输损耗报告并推进一周。原作教程目标为控制长沙；本次没有声称已通关原版或探索所有剧本。

直接观察到的机制：人物独立资源，行动消耗气力，下周气力恢复，角色身份限制命令，军队士兵与劳工、军饷和士气，铁路移动产生损耗，战报，战胜后可能需要收复地区。

本版设计的简化：固定十城路线图、确定性战斗、统一行动成本、每军每周一次移动、税收公式、十二周期限、长沙两周驻守胜利、敌方每周补员与固定强度反攻。初始资金和税收为可玩性调整，并非原作准确数值。未实现原作的全国地图、多剧本、历史事件、复杂外交、叛变、完整人物招募、天气、武器库存和真实敌军调动。

战力公式：`士兵 × (0.5 + 训练/100) × (0.4 + 士气/100)`。长沙守军防御倍率 1.5，其他地区 1.15。结果确定，适合学习和调试，不宣称还原原作隐藏算法。
