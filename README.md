# 湘南行军 · Godot 学习版

基于本机《Rise of the White Sun / 白日升》教程及正式湖南场景实玩观察制作的独立策略游戏原型。Godot 4.6.2 已运行验证。地图、城门、山脉、纸纹全部由程序绘制，没有导入原游戏素材。

## 打开与运行

在 Godot 项目管理器中选择「导入」，打开本目录的 `project.godot`，进入编辑器后按 **F5**。macOS 也可以双击「启动学习版.command」，使用 `/Applications/Godot.app` 启动。

设计分辨率 1440 × 900，窗口会等比缩放。字体优先使用系统中文字体；其他系统建议安装 Noto Sans CJK SC。无需插件和外部素材。

## 游戏操作

目标：十二周内占领长沙，再守住两周。

- 底部选择人物。两个人的气力、资金、支持者、人脉独立。
- 点击地图上的圆形部队标记；侧栏显示指挥官、士兵、劳工、训练与士气。
- 选择指挥官管理军饷与装备。招募劳工改善补给；操练提高战力。
- 点击相邻城市，在「地区」页行军或进攻。每次消耗 1 气力，可同周连续移动；欠饷不会阻止行军。
- 消灭守军后，到「部队」页花费 3 气力执行接管地区，才能取得税收和控制权。
- 唐生智可兴办实业、赈济安民。税收在周结算时进入唐的账户。
- 「下一周」恢复气力、收税、强化敌方守军。欠饷造成逃兵和士气下降。
- 控制长沙后，驻军战力至少 9,000 才能抵御反攻。连续守住两周即胜利。
- 顶部保存、读取使用 Godot 的 `user://campaign.json`，不会修改原游戏存档。

一条已通过规则测试的通关路线：

1. 第一周：选白崇禧和第七军，招募劳工，连续进攻株洲、长沙；推进一周。
2. 第二周：白接管长沙（3 气力），发饷（1 气力）；推进一周。
3. 第三周：唐转交 50 资金，白发饷驻守；推进一周即胜利。

新增操作：

- 点击城市打开宽屏地区档案：左侧查看税收与五阶层影响力，中间切换建设／治理／群众目录，右侧查看成本、效果、前置与不可执行原因。
- 电话、道路、学校从 10% 开始按周推进。维护费从该地区税收扣除；失去行政控制则暂停。
- 巡视消耗 3 气力，提高我方各地区阶层影响力并加速建设到最高 99%；完工由周结算触发。
- 道路在路线两端完工后，运输损耗减半；学校完工一次性提高学生与农民影响力。
- 农会消耗 4 气力、5 人脉，农民影响力 +5；解锁学习版「农会互助」。
- 部队记录步枪、机枪、火炮；战斗缴获、行军损失、补充装备影响战力。招新兵不会自动生成步枪。
- 存档升级为版本二，同时兼容版本一并自动补齐新字段。

第七军初始劳工少于士兵的两倍，因此第一次行军仍会有后勤损耗。这是有意保留的资源取舍。

## 从哪里读代码

- `scripts/campaign.gd`：纯规则层。人物、城市、军队用字典存储；执行行动前检查权限与成本，执行后发送 `changed` 信号。
- `scripts/strategic_map.gd`：地图显示。`_draw()` 画地形、铁路和标记；`_gui_input()` 将点击转换成城市或部队选择。
- `scripts/main.gd`：界面层。创建 Control 节点、连接按钮与规则方法，收到信号时刷新面板。
- `main.tscn`：入口场景。界面节点在运行时创建，所以编辑器里主要显示入口节点。
- `tests/test_campaign.gd`：规则检查，覆盖不能越权、失败不扣资源、欠饷、连续行军、接管、装备、建设、农会前置、税收、通关及旧存档迁移。

建议学习顺序：先看 `spend()` → `pay()` → `march()` → `next_week()`，再看 `changed.connect(refresh)`，最后看地图的绘制与点击。修改规则后无需改地图按钮。

可练习的修改：修改一座城市的税收；把操练收益从 12 调成 8；增加外交行动；将字典换成自定义 Resource；将代码生成的 UI 拆成独立 `.tscn` 场景。

## 原作观察与本版简化

已在本机原作 V1.86 中文教程中完成控制长沙的目标，周结算出现「大胜！15胜利点」。实玩包括人物资源、军队后勤、多次铁路行军、地区视察、电话电报建设、接管株洲、进攻长沙、接管长沙与胜利结算。详细复现依据见 `OBSERVATIONS.md`。已继续进入正式湖南场景，执行农会行动并推进周结算；仍未探索所有剧本。

直接观察到的机制：人物独立资源、气力周刷新、角色权限、劳工招募、运输损耗、政策跨周推进、五类社会阶层影响力、军队驻扎与行政控制分离、战斗缴获，以及周结算检查胜利。

本版已经按照实玩修正为连续行军、允许欠饷移动，以及 3 气力接管。欠饷惩罚、装备战力、政策速度、维护费、道路收益与农会互助均为透明的学习版设计，不宣称等于原作隐藏公式。

仍简化为固定十城路线图、确定性战斗、十二周期限、长沙两周驻守目标、敌方每周补员与固定强度反攻。未实现全国地图、多剧本、三阵营协作、复杂外交、叛变、完整人物招募、天气或真实敌军调动。正式场景的多阵营与政策树观察见 `OBSERVATIONS.md`。

战力：兵力乘训练、士气与步枪覆盖率，再加重武器贡献。长沙守军防御倍率 1.5，其他地区 1.15。详细数值直接写在 `campaign.gd` 中，适合学习和修改。
