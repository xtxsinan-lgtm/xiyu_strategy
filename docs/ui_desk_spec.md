# 「漆案舆图」界面规范（Godot 与网页版共用）

> 目标：主界面只留**舆图 + 少量常驻信息**，其余全部收进「案上器物」打开的抽屉。
> Godot（`ui/`）与网页版（`web/play.html`）使用同一套坐标、配色、字号、器物与抽屉编排；
> 两边规则内核不同（Godot = 月/季 MVP 规则，网页 = v1 规则），所以抽屉**内容**可以不同，**外壳一致**。

## 1. 舞台与分区

逻辑舞台 1920×1080，等比缩放；多余宽高按 Godot `stretch canvas_items + aspect expand` 的方式**扩展**（不留黑边）。
网页版用同样算法：`s = min(W/1920, H/1080)`，舞台宽 `W/s`、高 `H/s`，`transform: scale(s)`。

```
y=0    ┌──────────────────────────── TopBar 顶栏（漆黑）高 60 ─────────────────────────────┐
y=60   ├──────────────────────────────────────────────────────────────┬─────────────────┤
       │ MapDesk 舆图（画框 + 地图）                                    │ Outliner 军情栏  │
       │  ┌Drawer 抽屉（左上浮层，宽 880）┐                              │ 宽 300（绢色）    │
       │  │                              │                              │  · 所选          │
       │  └──────────────────────────────┘                              │  · 急报          │
       │                                                                │  · 本季军令      │
y=984  ├──────────────────────────── DeskBar 案上器物（漆黑）高 96 ──────┴─────────────────┤
       │ 7 件器物（每件等宽）                                            │ 用印 · 结束本季  │
y=1080 └─────────────────────────────────────────────────────────────────┴─────────────────┘
```

| 区域 | 锚点 / 尺寸 |
|---|---|
| TopBar | 顶部全宽，高 60 |
| MapDesk | left 0, top 60, right −300, bottom −96 |
| Outliner | 右侧，宽 300，top 60, bottom −96 |
| DeskBar | 底部全宽，高 96；右端 300 宽为「用印」按钮（与军情栏对齐） |
| Drawer | MapDesk 内 left 14, top 14，宽 880，高 ≤ MapDesk 高 − 28，内容滚动 |
| 回放横幅 | MapDesk 顶部居中，宽 640 |

## 2. 配色（漆 · 绢 · 朱 · 铜）

规则线：`ink` 的 35% 透明（`rgba(43,33,25,.35)`）；卡片边 20%。直角为主，圆角 ≤ 2px。
舆图上的势力色（汉郡/属国/各国本国色、道路地形色）**保持不变**，不随本规范改动。

## 3. 字体与字号

- 标题：楷体。网页 `LXGW WenKai`；Godot `SystemFont["LXGW WenKai","Kaiti SC","STKaiti","KaiTi","Songti SC"]`。
- 正文：黑体。网页 `"PingFang SC","Noto Sans SC",…`；Godot `font_provider.gd` 的 body_font。
- 字号：正文 14；注释 12；小标签 11；区块标题 16（楷）；抽屉标题 21（楷）；顶栏数值 20；题签 26（楷，字距 0.3em）。

## 4. 组件

- **面板**：silk 底，1px 规则线。
- **抽屉（装裱）**：silk 底，2px ink 外框 + 内缩 3px 的 1px bronze 细线；投影 `0 12px 32px rgba(20,14,8,.45)`。
  页眉 silk_2，高 52：左侧 30×30 朱印方块（白色楷体单字：城/诏/节/仓/符/史），标题（楷 21），副标题（muted 12），右侧快捷键提示 + 「×」。
- **区块标题**：楷 16 + 底部 1px 规则线，右侧可附 muted 注。
- **指标卡（KPI）**：silk_3 底，1px 20% 边；标签 11 muted，数值 20 ink。
- **按钮**：silk_3 底，1px ink 45% 边；悬停边与字变 cinnabar；主按钮 cinnabar 底 silk 字；禁用 45% 透明。
- **进度条**：高 6，silk_2 轨道。
- **顶栏**（漆面）：左 40×40 朱印（汉 / 匈）+ 人物（楷 17 on_lacquer）+ 剧本副标题（12 on_lacquer_muted）；中部 3–4 个指标，竖向 lacquer_line 分隔；右侧日期（楷 18）+ 菜单（纪事 / 存档 / 剧本 / 工作台，漆面幽灵按钮）。
- **案上器物**（漆面底，顶部 1px bronze 线）：每件为绢色「牍板」，高 72：左 34px 线描图标，右侧名称（楷 18）+ 动作说明（11.5 muted，含快捷键）。打开中：2px cinnabar 边 + silk_2 底 + 名称朱色。
- **用印按钮**：cinnabar 底，内缩 4px 的 1px bronze_hi 线，「结束本季」（月制为「结束本月」）楷 24 + 「Space · 已拟 N 令」12。
- **军情栏**：silk_2 底，左边 1px lacquer_line。三段：所选（紧凑卡片）/ 急报（左侧色条列表，可点击定位）/ 本季军令（队列）。

## 5. 舆图画框

- 底色 `#D9C8A3`；地图图像上叠 `rgba(242,227,186,.30)` 绢色罩和四角暗角。
- **画框带**：距 MapDesk 边 8px 的 1px ink 外线，内侧 22px 宽的框带（silk_2），框带内侧 1px ink 内线。
- **天干地支方格**（代替经纬度——本图为示意图，不按比例）：世界坐标每 100 单位一列（甲乙丙丁戊己庚辛壬癸），620/6 单位一行（子丑寅卯辰巳）。
  框带上按当前视图在格线处画刻度、在格中央写干支；舆图上可选画 6% 墨色的格线（「计里画方」意象）。
- **题签**（左上）：silk 卡，双线框；「西域诸国图」（楷 26，字距 0.3em）+ 「前119年 · 道里据《汉书·西域传》」（12 muted）。
- **指北**（右上）：直径 64 的圆 + 八角星，顶端「北」。
- **图层 / 图例**（左下）：一个「图层」按钮打开小浮层，内含图层开关与图例；主界面不再平铺芯片。
- **镜头**（右下）：竖排 ＋ / － / 全图 / 聚焦帅帐。
